# Model license handling

Reviewed against the linked publisher terms on 2026-10-17. GitHub Pages publishes the app and bundled license text, but no GGUF weights. A catalog GGUF is requested directly by the user's browser from the model host and written to the folder the user selects. The app writes the catalog's license files into that same `models/` folder before requesting any GGUF bytes. It checks those files before browser loading and before each browser inference. Already present catalog models can receive missing license files from **Save license**.

| Catalog models | License source | Files saved next to the GGUF | User-facing handling |
| --- | --- | --- | --- |
| Qwen3.5 2B, Qwen3 1.7B, Qwen2.5 1.5B, SmolLM3 3B, Granite 4.1 3B, MiniCPM5 1B and 2B | Each model's linked publisher page identifies Apache 2.0; see [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0.html) | `.LICENSE.txt` and `.SOURCE.txt` | License link in the catalog and while active. |
| Bonsai 8B Q1_0 | [PrismML Apache 2.0 license](https://huggingface.co/prism-ml/Bonsai-8B-gguf/blob/main/LICENSE) and [NOTICE](https://huggingface.co/prism-ml/Bonsai-8B-gguf/blob/main/NOTICE.txt) | `LICENSE.txt`, `NOTICE.txt`, `SOURCE.txt` | Original Bonsai 8B, listed as experimental for this browser runtime; license and publisher notice are saved before the GGUF download. |
| Bonsai 2 2B Q2_0 | [PrismML Apache 2.0 license](https://huggingface.co/prism-ml/Ternary-Bonsai-2-2B-gguf/blob/main/LICENSE) and [NOTICE](https://huggingface.co/prism-ml/Ternary-Bonsai-2-2B-gguf/blob/main/NOTICE.txt) | `LICENSE.txt`, `NOTICE.txt`, `SOURCE.txt` | Downloaded to the workspace for a local llama.cpp server; the bundled browser runtime does not load it. |
| Qwen2.5 3B | [Qwen Research License](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct/blob/main/LICENSE) | `LICENSE.txt`, `NOTICE.txt`, `SOURCE.txt` | Acknowledge the research-use terms before download or load; active model shows the noncommercial research/evaluation restriction. |
| Gemma 3 1B | [Gemma Terms](https://ai.google.dev/gemma/terms/) and [Prohibited Use Policy](https://ai.google.dev/gemma/prohibited_use_policy) | `LICENSE.html`, `PROHIBITED-USE.html`, `NOTICE.txt`, `SOURCE.txt` | Accept the terms and use restrictions before download or load; active model links to both terms and restrictions. |

The Qwen Research and Gemma NOTICE files use the text required by their respective terms. Bonsai's NOTICE is copied from the publisher's repository. Apache 2.0 requires a license copy and applicable attribution notices; no separate upstream NOTICE file was found for the other Apache catalog artifacts during this review. The `SOURCE.txt` file records both the GGUF source and original model license page. Bundled terms are snapshots; review them when catalog URLs or upstream terms change.

Needle tools use a separately downloaded browser engine. The app saves the pinned [needle-rs MIT license and NOTICE](https://github.com/Geekgineer/needle-rs) with its JavaScript and WebAssembly files in `engines/Needle/`. Original Needle weights receive the [publisher's MIT license from its earlier repository revision](https://github.com/cactus-compute/needle/blob/1807b1d230ba/LICENSE) before the weights and vocabulary download. Needle 2 receives the [Apache 2.0 license in its model repository](https://huggingface.co/Cactus-Compute/needle2/blob/main/LICENSE) before the `.cact` download. Engine and model files are checked against pinned SHA-256 hashes before loading.

The optional Kokoro speech engine saves the license files for [Kokoro](https://cdn.jsdelivr.net/npm/kokoro-js@1.2.1/LICENSE), [Transformers](https://cdn.jsdelivr.net/npm/@huggingface/transformers@3.5.1/LICENSE), [Phonemizer](https://cdn.jsdelivr.net/npm/phonemizer@1.2.1/LICENSE), and [ONNX Runtime](https://github.com/microsoft/onnxruntime/blob/v1.22.0/LICENSE) before its runtime files. The Transformers transcription engine also saves the ONNX Runtime license. An engine downloaded before these files were added needs the small license files downloaded to pass the current readiness check.

Custom GGUFs require a nonempty `<filename>.LICENSE.txt` alongside the model before download or browser use. The app cannot determine a custom model's actual license, required notices, redistribution permission, or use restrictions from a URL or filename. The person adding it must check the source terms and add any other required files. The app does not enforce licenses for external Ollama or API-hosted models, which are managed by their respective providers. This document records the implemented safeguards and source review; it is not a legal certification for every downstream use or model update.

Catalog downloads keep these files in each model folder under `models/`. Existing flat sidecars remain readable.
