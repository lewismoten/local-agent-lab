# Image library

Open **Images** from the workspace navigation to browse saved artwork from image generation, avatar packs, identity avatars, achievements, project and conversation icons, journal artwork, model and engine icons, and voice icons. Filter by use, favorites, named collection, avatar pack, or search text. Select a thumbnail to see the full image, prompt, tags, and download. An image can appear under more than one use when it is reused.

The library uses the workspace's saved PNG assets and current references. It also includes unassigned images so removing an icon does not erase its source image. Select the star on a tile to mark a favorite, or use **Edit** to name collections. Identity editing still offers saved images for reuse. New identity selections record the source asset ID, so the Images page can show that reuse.

Catalog variants in the same model family share one workspace icon. An icon previously saved for one variant appears across that family; editing the family icon replaces the older per-variant references without deleting their image assets.

Select **Batch icons** in Images to generate a matching set for model families, achievements (including hidden achievements), and identities. Choose missing icons, every icon, or every icon except uploaded artwork. Pick a style preset or enter a custom style, then edit the shared instructions before starting. The batch saves each icon as it finishes. **Stop** ends the run after the current image; selecting missing icons later resumes the remaining work. An image generator must be configured first.

When an older identity has an avatar PNG without a library link, the Images page checks exact image bytes. It restores a unique match automatically. If multiple saved images have the same bytes, it leaves the identity unchanged and shows the candidate names for review. The scan reads at most four saved images at once and stops when you leave the page.

New images created through the shared generator are saved at their original dimensions. PNG copies up to 20 MB use the image library folder. Larger images and formats that do not fit as PNG keep their original file under `harness/images/originals`, with a library reference to it. The browser shows an error toast if an image was created but saving it failed. Intermediate generation previews are not kept. To include older generated PNG, JPEG, WebP, AVIF, or GIF files, select **Find older images**. The scan checks project `library/generated`, image inspector `outputs/images`, motion first frames in `sources/generated`, and older Story Studio `assets/chat` and generated `assets/characters` files. It reads 12-byte image signatures and, where present, small provenance sidecars for prompts and model names. It saves references to existing files without duplicating their image bytes. Files above 20 MB show a placeholder thumbnail; preview works up to 50 MB, and larger files can still be downloaded from the preview dialog.

When an inspector output is already in Images, the scan checks matching prompt, model, time, size, and exact bytes in bounded chunks. It stores the output path on the existing tile. Later scans recognize that path after a reload, so the same image does not appear twice.
