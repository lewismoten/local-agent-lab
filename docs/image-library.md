# Image library

Open **Images** from the workspace navigation to browse images saved by avatar packs, identity avatars, achievements, project and conversation icons, journal artwork, model and engine icons, and voice icons. Filter by use, avatar pack, or search text. An image can appear under more than one use when it is reused.

The library uses the workspace's saved PNG assets and current references. It also includes unassigned images so removing an icon does not erase its source image. Identity editing still offers saved images for reuse. New identity selections record the source asset ID, so the Images page can show that reuse.

When an older identity has an avatar PNG without a library link, the Images page checks exact image bytes. It restores a unique match automatically. If multiple saved images have the same bytes, it leaves the identity unchanged and shows the candidate names for review. The scan reads at most four saved images at once and stops when you leave the page.

Generated previews that were never saved are not in this library. The broader checklist tracks capture of all generated images, favorites, and named collections separately.
