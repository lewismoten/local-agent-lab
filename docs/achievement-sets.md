# Achievement sets

Open **Achievements → Sets** to create, edit, select, import, or export a set. Each set contains a title, description, and icon subject prompt for every built-in milestone, including hidden milestones. Selecting a set changes the copy while preserving the original milestone IDs, counts, targets, unlock dates, and progress. **Original** restores the built-in copy.

The editor can draft all 23 entries with a loaded chat model. Choose a tone or edit the direction, then review every result before **Save and use set**. Generation works in small groups and can be stopped. A failed draft does not change the active set.

**Regenerate icons** opens Images with all achievement icons selected. Its style and global instructions remain editable. The active set supplies the subject prompt for each achievement; icon generation saves each image separately. Each custom set keeps its own artwork. Exported `.achievements.json` files include the set's copy, prompts, and compact PNG icons. Importing one creates a separate set and saves its icons in the destination workspace. Older copy-only set files remain importable.
